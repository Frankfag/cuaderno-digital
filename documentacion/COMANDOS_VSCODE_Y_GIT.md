# ☁️ SUBIR A GITHUB POR PRIMERA VEZ

Situarse en la carpeta raíz:

cd ruta-del-proyecto

---

Inicializar repositorio

git init

---

Agregar todo

git add .

---

Primer commit

git commit -m "Proyecto inicial"

---

Conectar con GitHub

git remote add origin URL_DEL_REPOSITORIO

Ejemplo:

git remote add origin https://github.com/usuario/la-huerta.git

---

Subir

git branch -M main

git push -u origin main

---

# ☁️ ACTUALIZAR PROYECTO

Cada vez que hagas cambios:

git add .

git commit -m "Descripción cambios"

git push

---

# 🚀 VERCEL

## Después del primer enlace con GitHub

Normalmente solo:

git add .

git commit -m "Cambios"

git push

Vercel desplegará automáticamente.
